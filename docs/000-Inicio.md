## 📝 Notas Rápidas

- Sistema por **BLOQUES** (5-7 videos de una vez)
- Procesamiento: **Scraping → Ideas → Imágenes → Guiones → Videos**
- Gemini Plus para imágenes (ya tienes suscripción)
- Claude para generación de ideas
- FFmpeg para compilación de videos
- Google Drive para sincronización automática
